VIDEO / MP3 DOWNLOADER - LINUX USER GUIDE
=========================================
Program by-->Tanjiur Rahman Twha

WHAT IS THIS?
A simple tool to download videos or MP3 songs from YouTube,
Instagram and many other sites. Just paste the link and click
Download. It helps you avoid the ads :)

NOTE: The Windows file "python Setup.bat" does NOT work on Linux.
Follow the steps below instead. The program itself works the same.
(Tested style: Ubuntu / Debian / Linux Mint)


FILE YOU NEED
-------------
1. Downloader.pyw  (keep it in any folder, for example Desktop)


FIRST TIME SETUP (do this once on each PC)
------------------------------------------
1. Connect to the internet.
2. Open the Terminal.
3. Run these commands one by one:

   sudo apt update
   sudo apt install python3 python3-tk python3-venv

   python3 -m venv ~/videodl
   ~/videodl/bin/pip install yt-dlp imageio-ffmpeg

4. Wait until each command finishes.

(Why? "python3-tk" is needed for the program window. "venv" makes a
separate safe place for the tools, so the auto-update works.)


HOW TO RUN
----------
1. Open the Terminal in the folder where Downloader.pyw is.
   (Tip: right-click inside the folder > "Open in Terminal")
2. Run this command:

   ~/videodl/bin/python Downloader.pyw

3. The program window will open.


HOW TO USE
----------
1. Wait until the message says "Ready!"
   (The first time may take a little longer.)
2. Copy a video link from YouTube or Instagram.
3. Click "Paste" (or paste the link in the box yourself).
4. Choose what you want from the list:
   - MP3 Song - Good (320kbps)    = best sound quality
   - MP3 Song - Medium (192kbps)  = smaller file size
   - Video - Max                  = highest video quality
   - Video - 1080p / 720p / 480p  = choose by quality and data use
5. Click "Download".
6. Wait for the progress bar to finish and the message
   "Success!" to appear.
7. Click "Open Download folder" to see your file.


WHERE ARE MY FILES?
-------------------
Downloads > MyDownloads
(Full path: /home/<your name>/Downloads/MyDownloads)


OPTIONAL: MAKE AN APP ICON IN THE MENU
--------------------------------------
1. In the Terminal, run:

   nano ~/.local/share/applications/videodl.desktop

2. Paste this (change YOUR_NAME and the path to where you saved
   Downloader.pyw):

   [Desktop Entry]
   Type=Application
   Name=Video MP3 Downloader
   Exec=/home/YOUR_NAME/videodl/bin/python /home/YOUR_NAME/Desktop/Downloader.pyw
   Terminal=false
   Categories=AudioVideo;

3. Save (Ctrl+O, then Enter) and exit (Ctrl+X).
4. Now search "Video MP3 Downloader" in your app menu.


UPDATES
-------
The tool updates itself once a day when you open it with
internet on. You do not need to do anything.


COMMON PROBLEMS AND FIXES
-------------------------
Problem: "Setup not working" message
Fix:     Check your internet and open the program again.

Problem: Download shows an error
Fix:     - Check that the link is correct and starts with http.
         - Make sure the video is public (not private).
         - Close the program, connect to the internet, and open
           it again so it can update itself. Then try again.

Problem: "No module named tkinter"
Fix:     Run:  sudo apt install python3-tk

Problem: "externally-managed-environment" error
Fix:     Do not use plain "pip install". Use the venv commands
         shown in the setup steps above.

Problem: "venv" command fails
Fix:     Run:  sudo apt install python3-venv

Problem: Emojis look like empty boxes
Fix:     This is only a font issue. The program still works fine.
         (Optional: sudo apt install fonts-noto-color-emoji)


OTHER LINUX TYPES
-----------------
Fedora:  sudo dnf install python3 python3-tkinter
Arch:    sudo pacman -S python tk
Then use the same venv and pip commands as above.

TO INSTALL ON ANOTHER PC
------------------------
Copy "Downloader.pyw" to a pendrive, put it in any folder on the
other Linux PC, and repeat the "FIRST TIME SETUP" steps.
